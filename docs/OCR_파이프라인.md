# OCR 데이터 수집 및 정제 파이프라인

## 개요

| 항목 | 내용 |
|------|------|
| 대상 문서 | 국립국어원_정겨운우리말.pdf (406페이지) |
| 목적 | 순우리말 이름 후보 어휘 추출 → RAG 인덱싱 입력 데이터 생성 |
| 도구 | EasyOCR (한국어), PyMuPDF, Python 3.x |
| 전체 흐름 | PDF → raw OCR → 정제 → 구조화 |

---

## 전체 파이프라인 한눈에 보기

```
국립국어원_정겨운우리말.pdf
        │
        ▼  [ocr_extract.py]  EasyOCR (CPU, gpu=False)
ocr_raw_full.txt   +  ocr_progress.json  +  ocr_log.txt

        │
        ▼  [구조화 스크립트]  표제어 [품사] 패턴 기반 항목 분리
ocr_structured.txt
        │
        ▼  [다음 단계]
ChromaDB 인덱싱  →  RAG 검색
```

**조사 오인식 처리 전략:**

| 패턴 | 방법 | 선택 이유 |
|------|------|----------|
| `올/흘` → `을` | 유니코드 받침 판별 | 받침 있는 음절 뒤에만 오므로 문맥 조건 명확 |
| `논/눈` → `는` (따옴표) | 따옴표 패턴 | 어원 설명 형식 특화, false positive 없음 |
| `틀/름/률/논/눈` → `를/는` (공백) | 제외 목록 + 공백 경계 | 내용어 제외 목록(`이름`·`이틀`·`시름` 등)으로 보호 |
| `틀/름` (앞글자 1개) | **미처리** | 앞 문맥 부족, false positive 위험 |

**잔존 오류 (의도적 미처리):**

| 유형 | 잔존 건수 | 미처리 이유 |
|------|----------|------------|
| 한자 OCR 실패 (`#`·`@`) | ~1,100개 | 이미지형 PDF + EasyOCR 한국어 전용 → 한자 인식 불가. PaddleOCR 재처리 필요 |
| 조사 오인식 잔존 | ~610건 | 앞 문맥 1글자뿐 → 판단 근거 부족, false positive 위험으로 제외 |
| 비정상 품사 태그 | ~10건 | 어원 표기(`발[서]`, `심-[늄]`)와 혼재, 본문 내용 손상 없음 |

## 다음 단계: RAG 인덱싱

`ocr_structured.txt`를 ChromaDB에 인덱싱하는 흐름:

```python
# 1. 파일 로드 및 항목 분리
with open('data/processed/ocr/ocr_structured.txt', encoding='utf-8') as f:
    content = f.read()

chunks = [
    c.strip() for c in content.split('\n\n')
    if c.strip() and not c.strip().startswith('===')
]
# → 약 4,316개 문서

# 2. 메타데이터 추출 (표제어·품사)
import re
POS = r'(?:명의|의존명사|접사|명|동|형|부|관|수|대|감)'
HEADER_RE = re.compile(r'^([가-힣]{2,}(?:\d{2})?)\s+(\[' + POS + r'\])')

documents = []
for chunk in chunks:
    m = HEADER_RE.match(chunk)
    documents.append({
        'text': chunk,
        'metadata': {
            'headword': m.group(1) if m else '',
            'pos':      m.group(2) if m else '',
            'source':   '국립국어원_정겨운우리말',
        }
    })

# 3. ChromaDB 저장
# collection.add(documents=..., metadatas=..., ids=...)
```

**질의 처리 시나리오 (project_idea_naming.md 기준):**
```
"김씨 성에 어울리는 순우리말 이름 추천해줘"
    → LangGraph internal_rag 노드
    → ChromaDB 유사도 검색 (우리말 이름 컬렉션)
    → 관련 어휘 항목 N개 리트리브
    → LLM 답변 + [출처: 국립국어원_정겨운우리말 p.8]
```

## 주요 OCR 오류 유형 참고

| 오류 유형 | 예시 | 처리 결과 |
|---------|------|---------|
| ㅡ↔ㅗ 모음 혼동 | `을→올`, `를→롤` | ✅ 올/흘→을 규칙 처리 |
| ㄹ↔ㅌ 자음 혼동 | `를→틀` | ✅ 공백 경계 규칙 부분 처리 |
| ㅂ↔ㅁ 자음 혼동 | `비→미` (`[비]→[미]`) | ✅ `[[미]→[비]` 규칙 처리 |
| ㅎ 받침 손실 | `놓고→농고` | ✅ 놓다 계열 17패턴 처리 |
| 었다↔없다 혼동 | 동사어간 뒤 `없다` | ✅ 었다/없다 규칙 처리 |
| 예문 마커 오인식 | `¶→끼`, `9`, `%`, `7` | ✅ 예문 마커 정규화 처리 |
| 뜻번호 마커 오인식 | `①②③→@` | ✅ 뜻번호 마커 규칙 처리 |
| false positive 발생 | `엿기름→엿기를`, `시름시름→시름시를` | ✅ 후처리 복원 10건 |
| 한자 인식 불가 | `한자→#`, `@` | ❌ 미처리 (PaddleOCR 재처리 필요) |
