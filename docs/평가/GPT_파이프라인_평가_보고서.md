# GPT 파이프라인 LLM-as-a-Judge 평가 보고서

> 작성일: 2026-06-17
> 시스템: 조건 기반 맞춤 작명 QA 시스템 (LangGraph + Hybrid RAG)
> 생성 모델: `gpt-5.4-mini` / Judge 모델: `gpt-5.4`

---

## 1. 평가 개요

### 시스템 구성

본 평가는 LangGraph 기반 ReAct 에이전트 파이프라인을 대상으로 한다. 사용자 질의가 입력되면 라우터가 적합한 도구(internal_rag, graph_db, sql_db, external_api)를 선택하고, 검색된 컨텍스트를 바탕으로 `gpt-5.4-mini`가 최종 답변을 생성한다.

| 항목 | 내용 |
|---|---|
| 생성 모델 | `gpt-5.4-mini` |
| 라우팅 | LangGraph ReAct (6방향 조건 분기) |
| 검색 도구 | ChromaDB RAG, Neo4j Graph DB, SQLite, 국가법령 API |
| Judge 모델 | `gpt-5.4` (생성 모델보다 상위 — 자기 평가 편향 최소화) |
| 평가 스크립트 | `tests/rag_eval.py` |

### 평가 지표

| 지표 | 정의 |
|---|---|
| **Context Relevance (CR)** | 검색된 컨텍스트가 질문에 답하기 위해 필요한 정보를 포함하는가 |
| **Groundedness (GR)** | 생성된 답변이 검색 컨텍스트에 근거하는가 (환각 여부) |
| **Answer Relevance (AR)** | 생성된 답변이 사용자 질문에 실질적으로 답하는가 |
