# 파인튜닝 sLLM(Qwen) API 연동 가이드 (팀원 공유용)

## 현행 구현 기준 보완 (2026-06-16)

> 문서 상태: 파인튜닝 Qwen 모델 API 테스트 가이드. 현재 운영 기본 모델 교체 문서가 아니라 별도 테스트 경로 안내 문서다.

현재 운영 서비스는 Open WebUI에서 Pipeline 서버로 질문을 전달하고, Pipeline 내부 LangGraph가 `gpt-5.4-mini`와 MCP Tool 계층을 사용해 답변을 생성하는 구조다. 본 문서는 해당 운영 경로를 변경하기 위한 지침이 아니라, Qwen 기반 sLLM을 OpenAI-compatible API 형태로 연결해 실험할 때 참고하는 검증용 가이드다.

| 항목 | 현재 기준 |
|---|---|
| 운영 기본 모델 | `gpt-5.4-mini` |
| 테스트 대상 모델 | `Qwen/Qwen3.5-4B` LoRA 실험 모델 |
| API 호환 방향 | OpenAI-compatible API 형태로 `ChatOpenAI(base_url=...)` 연결 가능 |
| 관련 코드 | `finetuning/serve_api.py`, `finetuning/run_inference.py` |
| 검증 필요 | RunPod 서버 URL, 현재 서버 가동 여부, 모델 아티팩트 경로는 실행 시점마다 별도 확인 필요 |

본문의 서버 주소나 정답률 표현은 로컬 저장소만으로 현재성을 검증할 수 없으므로, 발표/공유 전에는 실제 서버 가동 여부와 재현 가능한 테스트 결과를 함께 확인해야 한다.

현재 팀에서 파인튜닝한 **"작명 특화 Qwen3.5-4B (LoRA) 모델"**은 RunPod 환경에서 클라우드 API 서버 형태로 테스트할 수 있습니다.

각 로컬 환경의 **LangGraph 파이프라인 코드**에 실험 모델을 연결해 응답 형식과 품질을 확인할 수 있도록 접속 정보와 예시 코드를 정리합니다.

## 🔗 접속 정보 (API Endpoint)
현재 모델 서버는 Cloudflare 터널링을 통해 외부로 개방되어 있습니다.
* **API Base URL**: `https://minutes-interest-want-agent.trycloudflare.com/v1`
* **지원 포맷**: 100% OpenAI API 호환 (LangChain의 `ChatOpenAI` 모듈을 그대로 쓸 수 있습니다.)

> **[주의사항]**
> 위 주소는 제 RunPod 서버가 켜져 있는 동안만 유지되는 임시 터널링 주소입니다! 
> `Connection Error`가 발생하면 서버 실행 상태, Cloudflare 터널 주소, 모델 아티팩트 경로를 먼저 확인해야 합니다.

## 💻 랭그래프(LangChain) 파이프라인 수정 방법

로컬 실험을 진행할 때는 파이프라인 코드에서 LLM 모델을 정의하는 `ChatOpenAI` 부분만 아래 예시처럼 교체합니다. 환경 변수와 그래프 노드 구성은 실험 목적이 명확한 경우에만 별도로 조정합니다.

```python
from langchain_openai import ChatOpenAI

# ----------------------------------------------------
# [기존 코드] gpt-4o-mini 등을 호출하던 부분을 주석 처리하고
# [신규 코드] 아래 코드로 교체해 주세요!
# ----------------------------------------------------
sllm_model = ChatOpenAI(
    model="qwen-lora",  # 파인튜닝 모델 식별자 (서버에 지정된 이름)
    openai_api_key="sk-dummy-key",  # 아무 문자열이나 넣어도 패스됩니다.
    openai_api_base="https://minutes-interest-want-agent.trycloudflare.com/v1",  # RunPod 터널링 주소
    temperature=0.7,     # 창의성 조절 (추천값: 0.7)
    max_tokens=250,      # 답변 길이 (너무 길면 끊길 수 있으니 250~300 추천)
)

# 잘 작동하는지 간단한 테스트 코드
if __name__ == "__main__":
    print("🚀 클라우드 파인튜닝 모델로 질문 전송 중...")
    response = sllm_model.invoke("김씨 성을 가진 남자아이 이름 1개 지어줘")
    print("\n✅ 모델 응답 결과:")
    print(response.content)
```
