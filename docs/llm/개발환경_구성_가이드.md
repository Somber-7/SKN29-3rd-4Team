## 1. Ollama 설치

[https://ollama.com](https://ollama.com) 에서 Windows용 설치 파일 다운로드 후 설치.

설치 완료 후 브라우저에서 `http://localhost:11434` 접속 시 `Ollama is running` 확인.

### 모델 다운로드

```powershell
ollama pull qwen3.5:4b
```

설치 확인:

```powershell
ollama list
```

## 2. Open WebUI 설치 (Docker)

팀원들이 같은 WiFi 환경에서 브라우저로 접근 가능한 채팅 인터페이스.

### Docker Desktop 설치

[https://www.docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop) 에서 설치. 설치 후 새 터미널 창 열기 필요.

### Open WebUI 컨테이너 실행

```powershell
docker run -d `
  -p 3000:8080 `
  -e OLLAMA_BASE_URL=http://192.168.0.42:11434 `
  -v open-webui:/app/backend/data `
  --name open-webui `
  --restart always `
  ghcr.io/open-webui/open-webui:main
```

> `192.168.0.42` 는 Ollama를 실행 중인 노트북의 로컬 IP. 환경에 따라 변경 필요.  
> IP 확인: `ipconfig` 명령어에서 무선 LAN 어댑터 IPv4 주소 확인.

### 접속

- **호스트 노트북**: `http://localhost:3000`
- **팀원 (같은 WiFi)**: `http://192.168.0.42:3000`

최초 접속 시 관리자 계정 생성. 이후 팀원은 회원가입으로 접속.

## 3. Open WebUI 설정

### 모델 공유

관리자 계정으로 로그인 → 모델 설정 → 접근 권한을 공개로 변경.

### 성능 최적화 (필수)

Qwen3.5 thinking 모드 특성상 응답 후 추가 GPU 연산이 발생하는 문제 방지.

**Settings → Interface** 에서 아래 항목 전부 OFF:

- Auto-generate chat title
- Generate follow-up questions
- Auto Tagging
- Autocomplete

> 위 항목들이 켜져 있으면 응답 완료 후 추가 LLM 호출이 발생해 GPU가 계속 점유됨.

### 모델 고급 매개변수

모델 선택 → 편집(연필 아이콘) → Advanced Parameters:

| 파라미터 | 값 | 설명 |
|---|---|---|
| `num_ctx` | 32768 | Thinking 토큰 포함 전체 컨텍스트 크기. 부족하면 답변이 잘림 |
| `temperature` | 0.7 | 창의성 조절 |

## 4. LangChain + Ollama 연동

### 패키지 설치

```bash
pip install langchain-ollama
```

### 기본 사용법

```python
import ollama
from langchain_ollama import ChatOllama

client = ollama.Client(
    host="http://localhost:11434",
    timeout=300,
)

llm = ChatOllama(
    model="qwen3.5:4b",
    client=client,
    temperature=0.7,
    num_ctx=32768,
)

response = llm.invoke("질문 내용")
print(response.content)
```

> `timeout=300`: Thinking 모드에서 응답이 길어질 수 있어 5분으로 설정.  
> `num_ctx=32768`: Thinking 토큰이 기본값(2048)을 초과해 답변이 비어있는 문제 방지.

### 스트리밍

```python
for chunk in llm.stream("질문 내용"):
    print(chunk.content, end="", flush=True)
```

## 5. 트러블슈팅

| 증상 | 원인 | 해결 |
|---|---|---|
| 응답 완료 후 GPU 70~80% 지속 | Open WebUI 자동 생성 기능이 추가 LLM 호출 | Interface 설정에서 자동 생성 기능 전부 OFF |
| 팀원 화면에 모델이 안 보임 | Docker가 `host.docker.internal` 주소를 캐시 | 볼륨 삭제 후 컨테이너 재생성, `OLLAMA_BASE_URL`에 실제 IP 명시 |
| LangChain 응답 content 비어있음 | `num_ctx` 부족으로 thinking 도중 잘림 | `num_ctx=32768` 설정 |
| LangChain timeout 오류 | 기본 timeout이 짧아 thinking 완료 전 종료 | `ollama.Client(timeout=300)` 으로 직접 지정 |
