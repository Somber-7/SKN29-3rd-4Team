# 모델 교체 보고서

> 작성일: 2026-06-12
> 교체 대상: Router 노드 + Generate 노드
> 교체 방향: Qwen3.5:4b (로컬 Ollama) → GPT-4o-mini (OpenAI API)

---

## 1. 교체 배경

### 확인된 Qwen3.5:4b 문제

| 증상 | 원인 |
|---|---|
| 무한 반복 루프 ("최종 최종 답변:") | 4B 파라미터 — 반복 억제 한계 |
| 출력 형식 불준수 | 긴 시스템 프롬프트 + 형식 지시를 동시에 추적 불가 |
| 한자 오행·획수 수치 할루시네이션 | 도메인 지식 + 규칙 동시 처리 불가 |
| 미태깅 thinking 누출 | `reasoning=False` 설정에도 `<think>` 없이 추론 텍스트 출력 |

임시 조치(`num_predict=1536`, `repeat_penalty=1.5`, `stop=["⚠️ 면책 고지"]`)로 증상은 완화했으나 근본 원인(모델 규모) 해결 불가.

---

## 2. 교체 내용

### 변경 파일: `src/graph/naming_graph.py`

```python
# Before
from langchain_ollama import ChatOllama

_llm_router = ChatOllama(
    model="qwen3.5:4b",
    base_url="http://192.168.0.42:11434",
    num_ctx=4096,
    temperature=0,
    reasoning=False,
)

_llm_generate = ChatOllama(
    model="qwen3.5:4b",
    base_url="http://192.168.0.42:11434",
    num_ctx=16384,
    num_predict=1536,
    repeat_penalty=1.5,
    temperature=0.3,
    reasoning=False,
    stop=["⚠️ 면책 고지"],
)
```

```python
# After
from langchain_openai import ChatOpenAI

_llm_router = ChatOpenAI(
    model="gpt-4o-mini",
    temperature=0,
    max_tokens=512,
)

_llm_generate = ChatOpenAI(
    model="gpt-4o-mini",
    temperature=0.3,
    max_tokens=1536,
)
```

### 제거된 Qwen 전용 파라미터

| 파라미터 | 제거 이유 |
|---|---|
| `num_ctx=16384` | OpenAI API는 컨텍스트 윈도우 서버 측 관리 |
| `repeat_penalty=1.5` | GPT-4o-mini는 반복 루프 없음 |
| `reasoning=False` | ChatOpenAI에 해당 파라미터 없음 |
| `stop=["⚠️ 면책 고지"]` | 루프 차단 목적 — GPT는 불필요 |
| `base_url` | OpenAI 공식 엔드포인트 사용 |

### 변경 파일: `.env.example`

```
OPENAI_API_KEY=your_openai_api_key_here
```

## 3. 의존성

`requirements.txt`에 이미 포함됨:
```
langchain-openai==1.3.0
```

Docker 컨테이너 재빌드 시 별도 설치 불필요.

---

## 4. 환경 변수 설정

실행 전 `.env` 파일에 API 키 추가 필수:
```
OPENAI_API_KEY=sk-...
```

Open WebUI Pipelines 컨테이너는 `.env` 마운트 또는 컨테이너 환경 변수로 전달.

## 5. 예상 비용

| 구분 | 입력 토큰 단가 | 출력 토큰 단가 |
|---|---|---|
| gpt-4o-mini | $0.15 / 1M | $0.60 / 1M |

쿼리당 예상 소비:
- Router: ~800 input + ~100 output (JSON 1줄)
- Generate: ~3,000 input + ~1,000 output (이름 3개 기준)

쿼리 1회 ≈ $0.001 미만. 발표 당일 100회 테스트 기준 **$0.10 미만**.

## 6. 역할 분리 요약

| 노드 | 모델 | 역할 |
|---|---|---|
| Router | gpt-4o-mini | 다음 Tool 선택 (JSON 출력) |
| Generate | gpt-4o-mini | 최종 이름 추천 답변 생성 |
| sLLM (별도) | Qwen3.5:4b | QLoRA 파인튜닝 실험 — 평가 항목용, 서비스 미사용 |

Qwen3.5:4b는 서비스에서 제외되지만 **sLLM 파인튜닝 평가 항목 충족을 위해 유지**됨.
→ 상세 내용: [sLLM_파인튜닝_전략.md](./sLLM_파인튜닝_전략.md)

## 7. 후속 업그레이드

이 문서는 Qwen3.5:4b → GPT-4o-mini 교체를 기록한다. 이후 **GPT-4o-mini → gpt-5.4-mini** 추가 업그레이드가 진행되었다.

| 노드 | 현재 모델 |
|---|---|
| Router | gpt-5.4-mini |
| Generate | gpt-5.4-mini |
| Verify | gpt-5.4-mini |
