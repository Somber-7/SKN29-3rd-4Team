**프롬프트 이모지 전수 제거**:
- `✅ ❌ ⚠️ ⛔ ✓ ✗` 등 이모지를 텍스트로 교체
- 면책 고지의 `⚠️`만 유지

**[참고 정보] 블록 출력 제거**:
- `_invoke()` 내부에 regex 제거 로직 추가
- 시스템 프롬프트에 "[참고 정보] 블록을 답변에 포함하지 말 것" 명시

**개수 미달 안내 메시지 추가**:
- 요청 개수 > 실제 출력 시 답변 최상단에 "N개 중 M개 추천" 문구 삽입

**`_llm_verify` max_tokens 증가**:
- 1024 → 2048 (긴 이름 목록 검증 중 출력 잘림 방지)

## 현재 알려진 문제

| 문제 | 상태 | 비고 |
|------|------|------|
| 세션 간 이름 중복 (다른 채팅창) | 미해결 | 대화 이력 없으면 LLM 기본값(지은·민준 등) 반복 — 구조적 한계 |
| 흔하지 않은 성씨 오행 미표기 | 부분 해결 | `_SURNAME_DICT` 50개 이외 성씨는 반문으로 한자 수집, 오행은 미상 처리 |
| 외자 추천 이름 다양성 부족 | 미해결 | 외자는 음절 선택지가 좁아 반복 추천 가능성 존재 |
