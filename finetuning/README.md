# Qwen3.5-4B 파인튜닝 가이드 (v2)

본 디렉토리는 RunPod 환경에서 `Qwen/Qwen3.5-4B` 모델을 프로젝트 특화 모델(`gpt-5.4-mini` 대체용)로 파인튜닝하기 위한 스크립트를 포함합니다.

## 1. 8개 JSON 데이터의 이해와 활용

프로젝트에는 총 8개의 JSON 파일이 있습니다. 각각의 역할이 다르기 때문에 **구분하여 사용**해야 합니다.

### A. 학습(SFT)용 데이터 (1개)
- **`finetune_data_v2.json`**
- 구조: `{"instruction": "...", "output": "..."}`
- **용도**: 모델이 챗봇으로서 어떻게 대답해야 하는지(말투, 논리 전개 방식, 마크다운 포맷팅)를 훈련하는 핵심 데이터입니다.
- **처리 방식**: `train.py`가 자동으로 이 포맷을 인식하여 학습합니다.

### B. 지식 베이스(RAG)용 데이터 (7개)
- **`hanja_documents.json`, `law_articles.json`, `paper_documents.json`, `ohaeng_documents.json` 등 7개 파일**
- 구조: `{"document": "...", "metadata": {...}}`
- **용도**: 이 데이터는 모델의 가중치에 직접 암기시키는 것보다, 기존처럼 **ChromaDB(벡터 DB)에 넣어 RAG(검색 증강 생성)** 용도로 활용하는 것이 훨씬 효율적입니다.
- **처리 방식**: `train.py` 내부에서 이 파일들은 포맷이 다르므로 자동으로 **무시(필터링)** 하도록 안전장치가 마련되어 있습니다. 즉, 데이터 폴더에 8개가 섞여 있어도 에러 없이 `finetune_data_v2.json`만 뽑아서 학습합니다.

## 2. RunPod 실행 가이드

### 2.1. 인스턴스 스펙 권장
- **GPU**: VRAM 24GB 이상 (예: RTX 3090, RTX 4090, A5000, A100 등) 1대
- **디스크 공간**: 모델 다운로드 및 저장 공간을 위해 최소 50GB 할당 권장

### 2.2. 라이브러리 설치
```bash
pip install torch transformers peft trl datasets accelerate
```

### 2.3. 파인튜닝 학습 실행
```bash
cd finetuning
python train.py
```
- 스크립트 실행 시 `data/processed` 내의 모든 JSON을 검사하여 유효한 1,557건(또는 그 이상)의 QA 데이터를 솎아냅니다.
- `models/qwen3.5-4b-naming-qlora-v2` 폴더에 LoRA 어댑터가 저장됩니다.

### 2.4. 모델 성능 평가
```bash
bash eval.sh
```
- LM-Eval을 설치하고, 한국어 독해 능력(haerae)과 추론 능력(arc_challenge)을 파인튜닝 전후로 비교 평가합니다.
- 결과는 `eval_results/` 에 저장됩니다.

### 2.5. RunPod 예상 소요 시간 (RTX 4090 / A100 기준)
- **데이터 로딩 및 준비**: 1~2분
- **QLoRA 파인튜닝 (1,557건, 3 Epoch)**: 약 **10~15분** 내외
- **벤치마크 평가 (LM-Eval)**: 약 **10~20분** 내외
- **총 예상 시간**: 환경 셋업을 제외한 순수 실행 시간은 약 **20~35분** 정도 소요됩니다. 데이터가 작고 4B 모델이라 매우 빠릅니다.

## 3. 요약 및 파이프라인 통합
- 모델 차이 말고 파이프라인은 동일하게 유지하려면, 파인튜닝 후 `serve_api.py` (vLLM 등)에 이 LoRA 모델을 올려 로컬 API 서버를 열고, `naming_pipeline.py`에서 기존 OpenAI 엔드포인트(혹은 기존 로컬 엔드포인트) 대신 띄운 로컬 서버 IP를 바라보게만 수정하면 됩니다.
- 7개 문서는 계속해서 RAG 컨텍스트로 프롬프트에 제공되므로, 모델은 "자신이 파인튜닝으로 배운 말투"와 "RAG가 물어다 준 정확한 한자/오행 정보"를 결합하여 gpt-5.4-mini 수준의 답변을 내게 됩니다.
